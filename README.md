# Homecam — домашнее видеонаблюдение

Система видеонаблюдения, которая целиком работает в Docker: непрерывная запись с IP-камер,
живой просмотр с минимальной задержкой, архив с одновременным просмотром всех камер,
экспорт фрагментов, временные ссылки и оповещения в Telegram.

Стек: Ubuntu, Docker, Nginx, PHP 8.4, Laravel 13, SQLite, JavaScript (без сборки), FFmpeg,
go2rtc (ретранслятор живого видео в WebRTC/MSE).

## Как устроено

| Контейнер | Что делает |
|---|---|
| `app` | Nginx + PHP-FPM: веб-интерфейс, API, отдача файлов архива (через `X-Accel-Redirect`, после проверки доступа) |
| `worker` | `homecam:recorder`: по одному процессу ffmpeg на камеру, индексация роликов, ротация, проверка камер, оповещения в Telegram; `queue:work`: сборка экспортов |
| `go2rtc` | Живое видео: RTSP → WebRTC (задержка меньше секунды) или MSE через websocket. Доступ к нему только через nginx с проверкой входа |

Видео **не перекодируется** (`-c copy`), поэтому нагрузка на процессор минимальная.

### Хранилище

```
<SERVER_CAM_DATA_DIR>/
  rec/<камера>/<ГГГГ-ММ-ДД>/<ЧЧ>/<камера>_<ГГГГММДД>_<ЧЧММСС>.ts   ← ролики по 60 с
  exports/                                                         ← собранные MP4 для скачивания
```

Каждый ролик — самостоятельный файл MPEG-TS, его можно открыть в VLC, mpv, ffplay или
любом плеере, понимающем `.ts`. Время начала записано в имени файла (часовой пояс `TZ`).
Каталог `rec` можно скопировать куда угодно и смотреть без этой системы. Если скопировать
файлы обратно, команда `docker compose exec worker php artisan homecam:reindex` заново построит индекс.

### Ротация

Раз в минуту worker считает суммарный размер роликов и удаляет самые старые, пока размер
не станет меньше лимита (`STORAGE_LIMIT_GB`, меняется в «Настройках»). Отдельно следит,
чтобы на диске оставалось не меньше `MIN_FREE_GB` свободного места.

## Установка

1. Скопировать `.env.example` в `.env` и заполнить (сервер, `APP_KEY`, пароль администратора, лимит, Telegram).
2. С компьютера разработчика: `python tools/deploy.py` (нужен `pip install paramiko`).
   Скрипт загрузит проект в `/opt/homecam`, положит `.env` без SSH-учёток и выполнит `docker compose up -d --build`.
   Вручную на сервере то же самое: `docker compose up -d --build` в каталоге проекта.
3. Открыть `http://<сервер>:8080` (порт `APP_PORT`) и войти под `ADMIN_LOGIN` / `ADMIN_PASSWORD`.
4. Для WebRTC открыть порт `WEBRTC_PORT` (8555, TCP и UDP). Без него живое видео пойдёт через MSE, задержка чуть больше.

Камеры добавляются в веб-интерфейсе («Камеры» → «Добавить»). Учётные данные камер
хранятся в базе SQLite (`state/homecam.sqlite`) в зашифрованном виде (ключ `APP_KEY`), а не в git.
Из консоли: `docker compose exec app php artisan homecam:camera-add "Имя" rtsp://host:554/ --login=... --password=...`

## Telegram

1. Создать бота у @BotFather, получить токен.
2. Добавить бота в группу, узнать `chat_id` группы (например, через `https://api.telegram.org/bot<TOKEN>/getUpdates` после сообщения в группе; у групп он отрицательный).
3. Вписать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env` (если api.telegram.org недоступен напрямую, добавить `TELEGRAM_PROXY=http://user:pass@host:3128` или `socks5h://user:pass@host:1080`), перезапустить (`python tools/deploy.py --no-build`).
4. «Настройки» → «Отправить тестовое сообщение».

Камера считается недоступной, если от неё нет видео дольше `CAMERA_OFFLINE_AFTER` секунд.
Бот пишет, когда камера пропала и когда снова заработала.

## Возможности веб-интерфейса

- **Онлайн** — сетка всех камер, двойной клик или ⛶ открывает камеру на весь экран.
- **Архив** — интервал «с/по», выбор камер, все выбранные камеры играют синхронно по общей шкале времени;
  скорость до 16×, клик по шкале — переход, пробел — пауза, стрелки — ±10 с.
- **Экспорт** — в архиве отметить «[ начало» и «конец ]» и нажать «Скачать фрагмент»: для каждой камеры собирается один MP4.
- **Камеры** — добавление, удаление (с файлами или без), настройка, проверка подключения.
- **Ссылки** — временные ссылки без пароля: только онлайн, онлайн + архив, выбранные камеры, ограничение интервала архива, срок действия.
- **Настройки** — лимит хранилища, порог недоступности, тест Telegram, пользователи, смена пароля.

## Полезные команды (на сервере, в `/opt/homecam`)

```
docker compose logs -f worker              # запись, ротация, ошибки камер
docker compose exec app php artisan homecam:reindex
docker compose restart worker
```
